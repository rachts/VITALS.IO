API

Developer-First Unit Economics

Build unit economics into your internal dashboards. POST a CSV, get JSON back.

POST /analyze

Analyze startup unit economics from financial data

REQUEST BODY

{
  "mrr": 500000,
  "total_customers": 500,
  "new_customers": 100,
  "churned_customers": 25,
  "ad_spend": 200000,
  "sales_cost": 150000,
  "cogs": 50000
}

RESPONSE FIELDS

arpa
gross_margin_pct
churn_rate
ltv
cac
ltv_cac_ratio
payback
health_score
POST /predict/scenario

Run what-if scenarios on your unit economics

ADJUSTMENT FIELDS (add to /analyze payload)

churn_rate_adj      // e.g. -0.2 = 20% decrease
cac_adj             // e.g. 0.1 = 10% increase
mrr_growth_adj      // e.g. 0.15 = 15% growth
gross_margin_adj    // e.g. -0.05 = 5% decrease
GET /predict/status

Check prediction engine status

RESPONSE

{
  "status": "operational"
}
